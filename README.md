# Flashcard Quiz

A simple quiz app that uses flashcards to help users learn and test their knowledge.

## Features

* Multiple-choice questions
* Instant feedback
* Score tracking
* Simple and easy-to-use interface

## Technologies

* HTML
* CSS
* JavaScript

## How to Run

Open `index.html` in a web browser.

## Future Improvements

* Add more questions
* Add difficulty levels
* Save quiz scores
* Add categories
